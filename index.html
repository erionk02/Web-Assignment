The evolution of HTML

HTML1.0

HTML1.0 was introduced in 1993 by Tim Berners-Lee, this was the first vision of the HyperText Markup Language. The language was very simple but yet revolutionary markup language that the difined the structure and layout of web pages. The language supported only static content, it included a small set of tags, focusing on simple document structuring and linking. The best feature were hyperlinks, but there was no support for CSS ar any styling. (Ajay Dhangar, 2024)

HTML2.0

HTML2.0 was published in 1995 by the Internet Engineering Task Force (IETF), was the first standardized version of HTML. It had some new features that HTML1.0 didn't have. HTML2.0 established a set of guidelines for browser developers, ensuring a more consistent user experience. the form element, allowed developers to structure data in a tabular format, supported character entities for special characters like & and <. (Ajay Dhangar, 2024)

HTML3.2

HTML3.2 is W3C's specification for HTML, developed in early '96 together with vendors including IBM, Microsoft,Softquad etc. HTML 3.2 adds widely deployed features such as tables, appletes and text flow around images, while providing full backwards compability withthe existing standart HTML 2.0. In HTML3.2 limited styling was added like the color of the text and the backgroundcolor (World Wide Web Consortium, 2018)

HTML4.01

HTML4.01 was standarized under the auspices of the World Wide Web Consortium (W3C) and published in December 1999. HTML4.01 was a subversion of HTML 4. HTML 4 supports more multimedia options, scripting languages, style sheets, better printing facilities, and documents that are more accessible to users with disabilities. The changes between the two of them were mainly minor corrections and clarifications. (Librabry of Congres, 2018)

HTML5.1

HTML5 is the fifth version of Hypervision Markup Language, a standart language used to structure webpasges. It defines how content on a webpage should be structured and displayed. HTML5 provides multimedia support, adds new d=form controls like date and email input types, enables webs storage to store data offline, uses semantic elements such as <header> and <footer> for clearer structure and delivers improved performance, especially on mobile devices

Evolution of CSS

Origin and development

CSS was developed by the World Wide Web Consortium (W3C), with significant contributions from Hakon Wium Lie and Bert Bos. It was first proposed in 1994 by Hakon Wium Lie to adress the challanges of document presentation on the web, which was previously controlled solely by HTML

CSS1.0

CSS 1 was released in December 1996. It introduced basic features which were mostly very simple, like text styling, font properties, margin, padding, color and background styling (Sahil Chhabra, 2025)

CSS2.0

CSS2 was introduced in May 12th 1998. CSS2 included a number of new features such as absolute, relative and fixed position of elements, z-index for element overlap, minimum and maximum width or height of elements, type of media, etc. In June 2011,W3C published a revision of the second version of cascading styles, CSS2.1 (World Wide Web Consortium, 1998)

CSS2.1

CSS2.1 is a revision of CSS2 that corrects many errors and omissions in the CSS2. It has also dropped unimplemented fetures and introduced a handful of minor new ones (CSS Working Group. )

CSS3

CSS3 represents the last evolution of the stylesheet language used to describe the presentation of documents written in markup language such as HTML. Building upon the foundations of CSS2, CSS3 introduces a plethora of new features and functionalities that empower web developers to create richer, more interactive, and visually appealing web pages with less reliance on images and scripting. Key features of CSS3 are: Selectors, Box Model Enhacement, Text effect, Gradients, Transition, Animations, Transforms etc. (Grandel Robert, 2026)

Explanation of HTML tahgs and CSS used in my Assigment

You can find some of the tags I used in my website and what they are used for in the table below

Tag names What the tag is for
<html> This tag represents the root of an HTML document, so it also referred to as the root element.
<head> Contains machine-readable information (metadata) about document, like title, scripts, and style sheets.
<link> I used this to link my HTML file with my CSS file
<meta> Represents metadata that cannot be represented by other HTML meta-related elements, like <base>, <link>, <script>, <style> and <title>
<title> Defines the document's title that is shown in a browser's title bar or a page's tab.
<body> Represents the content of an HTML documents. There can be only one such element in a document.
<header< Represents introductory content, typically a group of introductory or navigational aids. It may contain some heading elements but also a logo, a search form, an author name, and other elements
<nav> Represents a section of the page whose purpose is to provide navigation links.
<section> Represents a generic standstone section of document, which doesn't have a more specific semanic elemenet to represent it.
<div> The generic container for flow content. It has no effect on the countent or layout until styled in some way using CSS
<p> Represents a paragraph. Paragraph are represented in visual media as blocs of texts seperated from adjacent blocks by blank lines and/or first line indentation.
<ul><li> ul represents an unorder list of items and li represents an item in the list
<a> Together with its href attribute, creates a hyperlink to web pages, files, email addresses, locations within the current page, or anything else a URL can address.
<img> Embeds an image into the document
<iframe> Represents a nested browsing context at the specified points in the document. This content is handled by the browser or an external application.
<table> Represents tabular data that is, information presented in a two dimensional table comprised of rows and colums cells containing data.
<th>, <tr>, <td> <tr> defines a row of cells in a table. <th> is a child of the <tr> element, it defines a cell as the header of a group of tab cells. <td> is a child of the <tr> element, it defines a cell of a table that contains data.
<h1>, <h2>, <h3>, <h4>, <h5>, <h6> Represents six levels of section headings. <h1> is the highest section level and <h6> is the lowest.
